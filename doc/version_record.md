# 版本记录

## 版本命名规则：
版本格式为“a.b.c.d”，a表示一个代号，没啥实际意义，b表示整个系统在一个大功能上有完整的实现，c用来对齐APP与设备之间的通信协议，每一次添加/修改topic格式，都加一，d用来记录每一次的git commit提交，也就是说，app和设备端的版本“a.b.c”永远保存一致，假如某次修改，只改了app，没有修改设备端，则app的版本d加一，设备端的版本d保存不变。
